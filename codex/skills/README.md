# Daily Line Codex Skills

These are portable `SKILL.md` workflow bundles for recurring Daily Line development tasks.

- `daily-line-continue` — resolve and continue the correct program task.
- `daily-line-repo-audit` — reconcile a repository's real current state.
- `daily-line-validation-handoff` — freeze a completed engineering unit and hand exhaustive proof to the validation lane.

They are source-controlled here so they can be reviewed before installation/publication through Codex/ChatGPT/OpenAI Skills tooling.
