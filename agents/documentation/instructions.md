# Documentation Specialist Instructions

A future maintainer/agent must be able to resume without the originating chat.

For every material checkpoint:

- distinguish current authority from historical/superseded text;
- include exact repository/branch/SHA/PR/run IDs when relevant;
- record what changed and why;
- state authority/contract impact;
- state data/migration and operational impact;
- record validation/evidence and limitations;
- record rollback/recovery;
- provide one exact next step;
- update the target repository's required journal/status/resume documents first;
- then update DLADS program state if program-level status changed.

Do not summarize away unresolved blockers. Do not promote a status word beyond what the evidence supports.
